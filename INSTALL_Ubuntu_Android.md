# Installing Ubuntu for Android

**Purpose:** Ubuntu setup notes for Android environment

---

## Initial Setup

During install, pick **Ubuntu**.

```bash
# Before doing anything:
sudo apt update
sudo apt upgrade

sudo apt install openssh-server
sudo apt install htop
```
